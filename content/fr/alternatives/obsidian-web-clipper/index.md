## Obsidian Web Clipper

Obsidian Web Clipper est gratuit et open source. C'est une extension de navigateur qui enregistre les pages web, les surlignages et les métadonnées en notes Markdown dans votre coffre Obsidian.

Si vous travaillez déjà dans Obsidian, c'est un très bon outil : modèles, fichiers locaux, liens entre les notes.

Mais il est fait pour Obsidian. C'est une façon de prendre des notes, pas une liste de lecture.

## Deux habitudes différentes

- Avec **Obsidian Web Clipper**, vous gardez une page sous forme de note, pour travailler dessus plus tard.
- Avec **wallabag.it**, vous sauvegardez un article pour le lire plus tard dans une vue épurée, sur le web, sur votre téléphone ou sur votre liseuse.

Vous pouvez utiliser les deux : wallabag.it pour lire, Obsidian pour les notes que vous voulez vraiment garder.

## Ce que fait wallabag.it

- Il garde l'article entier, pas seulement le lien. Si la page disparaît, vous l'avez toujours.
- Vous lisez sur le web, sur Android, sur iOS et sur les liseuses Kobo ou PocketBook. Hors connexion aussi.
- Tags, recherche, surlignage et annotations.
- Vous pouvez tout exporter quand vous voulez : PDF, ePUB, mobi, JSON, CSV…
- C'est hébergé en Europe. Pas de pub, pas de pistage : ce sont les abonnements qui paient.
- C'est le wallabag open source, le projet que j'ai lancé en 2013. Si vous préférez l'héberger vous-même, c'est possible.
