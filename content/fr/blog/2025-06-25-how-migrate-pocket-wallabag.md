Pocket a fermé. Si vous y aviez une liste de lecture, vous pouvez la récupérer sur wallabag.it. Ça prend une dizaine de minutes.

## Étape 1 : exportez vos données Pocket

1. Allez sur [getpocket.com/export](https://getpocket.com/export)
2. Téléchargez le fichier d'export, un CSV avec toutes vos URL sauvegardées

Si vous n'avez plus accès à votre compte Pocket, regardez si Mozilla vous a envoyé un email d'export.

## Étape 2 : créez un compte wallabag.it

C'est [par ici](https://app.wallabag.it/register/) : 14 jours d'essai gratuit, sans carte bancaire.

## Étape 3 : importez vos données

1. Dans votre compte, ouvrez **Import** dans le menu de gauche
2. Sélectionnez **Pocket**
3. Chargez le fichier CSV de l'étape 1

wallabag.it récupère le contenu de chaque article. Vos articles arrivent dans votre liste de lecture en quelques minutes, et vos tags Pocket sont conservés.

## Étape 4 : installez les applications

- **Navigateur** : l'[extension Firefox](https://addons.mozilla.org/firefox/addon/wallabag-v2/) ou l'[extension Chrome](https://chrome.google.com/webstore/detail/wallabagger/gbmgphmejlcoihgedabhgjdpkiiiljog)
- **Android et iOS** : l'application mobile, pour lire hors connexion
- **Liseuse Kobo** : wallabag.it se connecte directement aux appareils Kobo

Pour comparer avec d'autres services, j'ai aussi écrit [une page sur les alternatives à Pocket](/fr/alternatives/pocket/).
